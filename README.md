# Cat Calorie Calculator 🐱

Free single-page tool: **how much should I feed my cat?**

Enter weight, life stage, neuter status and activity level → get a daily calorie target (kcal/day) plus food amount in grams, based on the standard veterinary **RER / DER** formulas:

- `RER = 70 × weight_kg^0.75`
- `DER = RER × factor` (1.2–1.4 neutered adult · 1.4–1.6 intact · 2.5 kitten · 1.1–1.3 senior · 0.8 weight loss)

## Stack

Pure static — `index.html` only (inline CSS/JS). No build, no backend. Deploy anywhere: Vercel, Cloudflare Pages, Netlify, GitHub Pages.

## Disclaimer

Estimates only, not veterinary advice. Always consult your vet, especially for weight loss.
